Web上のデータを自動で収集して業務効率化を図りたいものの、「プログラミングの壁」に阻まれて諦めていませんか？

現在、次世代AIコードエディタ「Cursor」と高性能AIモデル「Claude 3.5 Sonnet」を組み合わせることで、非エンジニアであってもわずか数分で実用的なWebスクレイピングツールを開発できるようになっています。

本記事では、環境構築から実際のツール作成、データ保存までの手順を分かりやすく解説します。

## なぜCursorとClaude 3.5 Sonnetの組み合わせが最強なのか？

従来の開発では、プログラミング言語の文法を学び、エラーの原因を自分で調べて解決する必要がありました。しかし、CursorとClaude 3.5 Sonnetを連携させると、日本語でやりたいことを指示するだけで高度なコードが自動生成されます。

特にClaude 3.5 Sonnetはコーディング能力と文脈理解力が高く、複雑なWebサイトの構造を解析するコードも正確に作成してくれます。

| --- | --- | --- |
| 必要な知識 | Python, HTML/CSS, ターミナル操作 | 日本語での指示出し（プロンプト作成） |
| 開発時間 | 数時間〜数日 | 5分〜15分 |
| エラー対応 | 検索エンジンで自力調査 | エラー文をそのままAIチャットに貼るだけ |

## 事前準備：開発環境を整える3ステップ

ツールを作成する前に、最小限の準備を行いましょう。

### 1. Cursorのインストール
Cursorの公式サイトからお使いのPC（Windows / Mac）に対応するインストーラーをダウンロードしてインストールします。（※料金プランや仕様は執筆時点のものです。最新情報は公式サイトをご確認ください）

### 2. モデルの設定
Cursorを起動し、設定画面（Settings）から使用するモデルとして「claude-3-5-sonnet」が有効になっているか確認します。必要に応じてプロプランなどの登録を検討してください。

### 3. Pythonのインストール
スクレイピングコードを実行するためにPythonをPCに導入します。公式サイトから最新版をダウンロードし、インストール時に「Add Python to PATH」にチェックを入れておきましょう。

## 実践！スクレイピングツールを爆速で作成する手順

今回は、特定サイトからニュースの見出しとURLを取得し、CSVファイルに保存するツールを作成してみます。

### ステップ1：プロンプトで指示を出す
Cursorで新規ファイル（`scraper.py`）を作成し、`Cmd + K`（Windowsは`Ctrl + K`）を押してインラインチャットを起動します。以下のプロンプトを入力してください。

> 「PythonでWebスクレイピングのコードを書いてください。指定したURL（例: https://news.example.com ）から記事のタイトルと詳細ページのURLを取得し、pandasを使ってdata.csvというファイルに保存するスクリプトにしてください。ライブラリはBeautifulSoupとrequestsを使用してください。」

### ステップ2：コードの生成と適用
AIが生成したコードを確認し、「Accept」ボタンを押してファイルに反映させます。必要なライブラリがない場合は、Cursor内のターミナルで表示されたインストールコマンド（`pip install requests beautifulsoup4 pandas` など）を実行します。

### ステップ3：コードの実行とエラー修正
ターミナルで `python scraper.py` を実行します。もしエラーが発生した場合は、エラーログをコピーして `Cmd + L`（Chat機能）に貼り付け、「このエラーを修正してください」と送信するだけで、AIが原因を特定してコードを自動修復してくれます。

## 非エンジニアが知っておくべきスクレイピングのマナー

スクレイピングを行う際は、技術面だけでなく法的な配慮やマナーが重要です。

- **利用規約の確認**: 収集対象サイトの利用規約でスクレイピングが禁止されていないか必ず確認してください。
- **アクセス負荷の軽減**: 連続アクセスを避けるため、コード内に `time.sleep(1)` などを挟んでサーバーに負荷をかけないようにします。
- **robots.txtの確認**: サイトの `robots.txt` を確認し、クローリングが拒否されているページへのアクセスは避けましょう。
